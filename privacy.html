Privacy Policy

Hermes Google Access - last updated 23 October 2026

Scope

Hermes Google Access is a private, single-user tool. It is authorised on one Google account only, belonging to its operator (Jan Dolezal), and it accesses no other account.

What data is accessed

With the account owner's consent, the app uses these Google API scopes:

  • drive - read and write files in the owner's own Google Drive.
  • documents - read and edit the owner's Google Docs.
  • spreadsheets - read and edit the owner's Google Sheets.
  • calendar - read and create events in the owner's own Google Calendar.

In practice this means university coursework files, thesis documents, spreadsheets and the owner's own calendar. No Gmail messages, contacts or photos are requested or read.

How the data is used

The data is used only to carry out tasks the account owner asks for, such as creating a document, editing a spreadsheet, moving a file or adding a calendar event. It is not used for advertising, profiling, analytics or training machine-learning models.

Where the data goes

  • No Google user data is sold, rented or shared with any third party.
  • OAuth tokens are stored on the operator's own private server and are not shared.
  • Data is not transferred to anyone else, except back into the same Google account.

The app follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and deletion

Files created by the app live in the owner's own Google Drive. The operator can delete any of them at any time from Drive. Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops all further access.
